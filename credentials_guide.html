1. Firebase Authentication Credentials

Purpose & Utility

Firebase provides secure client-side authentication, account registration, session management, and password encryption for customers on the Viśvam Harvest platform.

Step-by-Step Instructions to Obtain Credentials:
  1. Log in to the Firebase Console at https://console.firebase.google.com using your Google account.
  2. Select your project (or click Add Project to create a new project named Visvam Harvest).
  3. Click the Settings (Gear) Icon in the left navigation sidebar and choose Project Settings.
  4. In the General tab, scroll down to the Your apps section and click the Web icon (</>).
  5. Enter Visvam Web as the App Nickname and click Register App.
  6. Select the Config radio button under SDK setup and configuration.
  7. Copy and provide the following 6 configuration values:
• apiKey
• authDomain
• projectId
• storageBucket
• messagingSenderId
• appId

2. Cloudinary Centralized Media CDN Credentials

Purpose & Utility

Cloudinary acts as the centralized image database and Content Delivery Network (CDN) for storing high-resolution product photography and packaging graphics. It automatically optimizes image sizes, ensuring fast page load speeds and enabling direct image uploads from the Admin Panel.

Step-by-Step Instructions to Obtain Credentials:
  1. Log in to your account at https://cloudinary.com.
  2. Navigate to the main Dashboard from the left sidebar.
  3. Locate the section titled Product Environment Credentials.
  4. Copy and provide the following 3 values:
• Cloud Name
• API Key
• API Secret (Click "View API Secret" to reveal)

3. MongoDB Database Connection String

Purpose & Utility

MongoDB serves as the central cloud database for Viśvam Harvest. It persistently stores product details, customer orders, shipping addresses, inventory stock levels, newsletter subscriptions, and concierge inquiries.

Step-by-Step Instructions to Obtain Connection String:
  1. Log in to MongoDB Atlas at https://www.mongodb.com/cloud/atlas.
  2. Under Security in the left menu, select Database Access ➔ Click Add New Database User. Create a user (e.g., visvam_admin) and set a strong password.
  3. Under Security, select Network Access ➔ Click Add IP Address ➔ Choose Allow Access from Anywhere (0.0.0.0/0) and confirm.
  4. Navigate to Database Deployments and click the Connect button next to your cluster.
  5. Select Drivers (Node.js).
  6. Copy the provided connection string. Replace <password> with the database user password created in Step 2.
Format: mongodb+srv://username:password@cluster.mongodb.net/visvam_harvest?retryWrites=true&w=majority
